# OpenFWI example data

These four samples were extracted by the DLO-FWI authors from OpenFWI. The original
velocity/observation files and zero-based sample indices are recorded in
`manifest.json`; the additional initial velocities are Gaussian-smoothed
versions of the supplied ground truth, as described there.
